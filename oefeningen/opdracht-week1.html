Oefening week 1: Python-basis

Fase 0 · Fundament · variabelen, datatypes, lijsten, dictionaries, if, for

Doel: je kunt de vier basistypen benoemen, het verschil tussen een lijst en een dictionary uitleggen in termen van hoe je een element ophaalt, en een lus met een voorwaarde schrijven.

Begrippen om bij de hand te hebben

De vier datatypen

TypeVoorbeeldWaarvoor
int5hele getallen
float12.50kommagetallen
str"Albert Heijn"tekst, tussen quotes
boolTrue / Falsewaar of niet waar

Python kiest het type zelf. Met type(x) vraag je wat hij koos. Dat is je eerste controle als iets zich vreemd gedraagt.

Let op: 12.50 en "12,50" zijn iets heel anders. Het eerste kun je optellen, het tweede is tekst. Nederlandse bankexports gebruiken een komma, dus dit wordt in fase 1 je hoofdpijn.

Lijst tegenover dictionary

LijstDictionary
Schrijf je als["brood", "kaas"]{"brood": 2.50}
Element ophalen meteen positie: lijst[0]een sleutel: dict["brood"]
Tellen begint bijnulniet van toepassing
Volgorde onthoudenjaja, sinds Python 3.7

Het verschil is dus niet "geordend of niet", maar waarmee je erbij komt: positie of sleutel.

for en if

for bedrag in bedragen:
    print(bedrag)

if totaal > 50:
    print("boven de 50")

Let op de dubbele punt en de indentatie. In Python bepaalt witruimte wat binnen de lus of de voorwaarde valt. Dat is de fout die je de eerste week het vaakst maakt.

De opdracht

Schrijf dit in oefeningen/01_basis.py en draai het met uv run oefeningen/01_basis.py. Experimenteren mag in klad.ipynb, maar het eindresultaat van week 1 is een script.

  1. Maak een lijst met vijf omschrijvingen van uitgaven, als tekst.
  2. Maak een dictionary die elke omschrijving aan een bedrag koppelt.
  3. Print het derde item uit de lijst.
    Hint: tellen begint bij nul. Welk getal heb je dus nodig?
  4. Print het bedrag van één omschrijving, via de dictionary.
  5. Print van beide het type met type().
  6. Probeer ook prijzen[1] op je dictionary. Voorspel eerst wat er gebeurt, draai het dan.
    Dit geeft een foutmelding, en dat is de bedoeling. Lees hem: zegt Python dat de sleutel niet bestaat, of dat je iets verkeerds probeert? Dat onderscheid is het hele punt van deze opdracht.
  7. Schrijf een for-lus die alle bedragen bij elkaar optelt, en print het totaal.
    Loop je door de lijst of door de dictionary? Bij een dictionary levert for je standaard de sleutels. Zoekterm voor de waarden: .values()
  8. Schrijf een if die print of het totaal boven de 50 euro ligt of niet.

Werkafspraak

Schrijf het zelf, ook als het lelijk wordt. Loop je vast op een foutmelding, onderzoek die dan eerst 15 tot 20 minuten zelf: lees de traceback van onder naar boven, kijk welk type fout het is en welke regel wordt genoemd. Kom daarna met wat je probeerde en wat er stond.
